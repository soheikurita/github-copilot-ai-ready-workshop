# ADR-0001: 商品画面のルーティングに React Router を使う

- ステータス: 採用
- 日付: 2026-07-16

## 背景
商品ごとの URL `/product/:id` と、一覧・詳細間のブラウザ履歴を扱う必要がある。

## 決定
`react-router-dom` 7.18 をランタイム依存に追加し、React Router で画面を構成する。

## 理由
宣言的なルート、URL パラメーター、リンク、履歴操作を一貫した API で扱え、
直接アクセスやテスト時のルート再現も容易になるため。

## 却下した代替案
History API と `popstate` による自前実装は依存を増やさない一方、
URL 解析、購読解除、履歴同期をアプリ側で保守する必要があるため採用しない。

## 影響
ブラウザ向けバンドルに React Router が加わる。
採用版は Node.js 20 以上、React / React DOM 18 以上と互換性がある。
